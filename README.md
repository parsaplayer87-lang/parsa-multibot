# 🤖 parsa-multibot — بات دانلودر و جستجوگر همه‌چیز برای **بله**

سه بازو در یک پروژه، هاست ۲۴/۷ روی GitHub Actions (رایگان)، دیتا در ریپوی خصوصی:

| بازو | آدرس | نقش |
|---|---|---|
| اصلی | [@prsdownbot](https://ble.ir/prsdownbot) | همه امکانات برای همه |
| پشتیبان | [@prsdownbackupbot](https://ble.ir/prsdownbackupbot) | همان امکانات (اگر اصلی مشکل داشت) |
| ادمین | [@12parsaadmanag1134bot](https://ble.ir/12parsaadmanag1134bot) | همه امکانات + پنل مدیریت کامل |

## ✨ امکانات
- **📥 دانلودر همه‌چیز**: یوتیوب، اینستاگرام، پینترست، تیک‌تاک، توییتر/X، آپارات، ساندکلاد و صدها سایت (با yt-dlp). اول تامبنیل + مشخصات + لیست کیفیت‌ها با حجم تخمینی → بعد تأیید کاربر → دانلود با صف و پیشرفت زنده.
- **🔍 جستجوی وب**: مثل موتور جستجو — ۵ سایت اول با *اسکرین‌شات واقعی از هر صفحه* + دکمه «۵ نتیجه بعدی». کلیک روی هر نتیجه → صفحه به‌صورت کاملاً حرفه‌ای ذخیره می‌شود: فایل **MHTML زنده** (HTML+CSS+JS با همه عملکردش — در Chrome/Edge باز کن) + اسکرین‌شات.
- **▶️ یوتیوب**: جستجو دقیقاً مثل موتور جستجوی یوتیوب؛ ۵ ویدیو با تامبنیل به صورت آلبوم عکس؛ دکمه دانلود با کیفیت ۱۰۸۰/۷۲۰/۴۸۰/۳۶۰ یا فقط صدا؛ «۵ ویدیوی بعدی».
- **🐙 گیت‌هاب**: جستجوی ریپو (نام، توضیح، ستاره) + دانلود ZIP ریپو برای کاربر. لینک ریپو را هم بفرستی، مشخصات + دکمه ZIP می‌دهد.
- **🔗 لینک شخصی**: در بخش وب اگر لینک بدهی، می‌پرسد: «فقط اسکرین‌شات / فقط ذخیره صفحه / هر دو».
- **⚙️ پنل مدیریت inline** در /start همه بات‌ها + **🛡 پنل ادمین** کامل.
- **🛡 پنل ادمین** (پیامی + مینی‌اپ): آمار زنده، لیست تمام کاربران با تمام جزئیات، **لاگ کامل همه پیام‌هایی که هر کسی می‌نویسد** (چون دیتا حیاتی است)، لاگ دانلودها، ارسال همگانی از هر سه بات، روشن/خاموش کردن هر قابلیت در هر بات، بن، خروجی JSON/CSV.
- **🌐 مینی‌اپ ادمین**: روی GitHub Pages، داده‌ها با **AES-256-GCM** رمز می‌شوند؛ کلید فقط در لینک ادمین است. اگر مینی‌اپ کار نکرد، پنل پیامی جایگزین کامل است. از داخل مینی‌اپ هم دکمه‌های sendData به بات فرمان می‌فرستند.
- **🧰 ابزارها**: QR code، آب‌وهوا (Open-Meteo رایگان)، ترجمه.
- **⚙️ مهندسی**: صف دانلود مرکزی (۲ دانلود همزمان، ۲ کار برای هر کاربر)، ضداسپم، محدودیت ۴۸MB (سقف آپلود بله)، ذخیره/بازیابی دیتابیس در ریپوی خصوصی هر ۱۰ دقیقه + موقع خاموشی.

## 🔄 معماری ۲۴/۷ روی GitHub Actions
```
schedule (*/20 دقیقه) ──┐
                        ├─► run فعال (حداکثر ~5.8h) ── خروج نرم بات ──► push دیتا ──► تریگر run بعدی
always-step (تریگر مجدد) ┘        │
                                  └─ اگر کرش کرد: cron ۲۰ دقیقه بعد، run آماده بعدی را بالا می‌آورد
```
- `concurrency: bot-run` ⇒ همیشه فقط یک بات فعال + یک pending در صف (بدون دانلود دوبله، بدون خاموشی).
- ریپوی کد **public** است ⇒ دقیقه اکشن نامحدود و رایگان. توکن‌ها فقط در **Secrets**.
- دیتابیس (همه کاربران و پیام‌ها) در ریپوی **خصوصی** `parsa-multibot-data` هر ۱۰ دقیقه commit می‌شود.
- ریپوی کد هر پایان run یک heartbeat commit می‌گیرد تا schedule بعد از ۶۰ روز غیرفعال نشود.

## 🔐 Secrets (ست‌شده)
`BOT_MAIN_TOKEN`, `BOT_BACKUP_TOKEN`, `BOT_ADMIN_TOKEN`, `ADMIN_ID`, `GH_PAT`, `ADMIN_WEB_KEY`, `GH_OWNER`, `DATA_REPO`, `ADMIN_WEB_URL`, `YTDLP_COOKIES` (اختیاری)

## 🍪 کوکی (اختیاری — برای اینستاگرام/یوتیوب محدود)
محتوای `cookies.txt` با فرمت Netscape را در Secret `YTDLP_COOKIES` بگذار؛ در runtime به yt-dlp داده می‌شود.

## 🛠 اجرای محلی
```bash
pip install -r requirements.txt
playwright install chromium
export BOT_MAIN_TOKEN=... BOT_BACKUP_TOKEN=... BOT_ADMIN_TOKEN=...
export ADMIN_ID=123456      # یا خالی → اولین /start در بات ادمین claim می‌شود
export SHUTDOWN_MINUTES=0
python -m bot.main
```

## 📁 ساختار
```
bot/
  baleapi.py    کلاینت Bale Bot API (long polling، آپلود فایل، rate-limit aware)
  handlers.py   مسیریابی پیام/دکمه‌های هر ۳ بات
  downloader → dqueue.py (صف) + ytdlp.py (yt-dlp wrapper)
  websearch.py  سرچ وب + MHTML زنده + اسکرین‌شات
  ytsearch.py   سرچ/دانلود یوتیوب
  gh.py         سرچ/دانلود گیت‌هاب (ZIP)
  tools.py      QR / آب‌وهوا / ترجمه
  admin.py      پنل ادمین + broadcast + export
  db.py         SQLite (users/messages/downloads/searches/settings)
  datastore.py  sync دیتابیس به ریپوی خصوصی + snapshot رمزنگاری‌شده مینی‌اپ
  main.py       اجرای ۳ بات + خروج نرم برای زنجیره Actions
adminweb/index.html   مینی‌اپ پنل ادمین (به ریپوی Pages پوش می‌شود)
.github/workflows/bot-24-7.yml  چرخه ۲۴/۷
```
