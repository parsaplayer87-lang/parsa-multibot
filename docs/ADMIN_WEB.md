# مینی‌اپ / پنل ادمین — parsa-multibot

این ریپو فقط `index.html` (پنل ادمین) و `snapshot.enc` (اسنپ‌شات رمزنگاری‌شده‌ی داده‌ها) را نگه می‌دارد و روی GitHub Pages سرو می‌شود.

## نحوه کار امنیت
- بات، هر ۱۰ دقیقه snapshot دیتابیس (کاربران، پیام‌های اخیر، دانلودها، وضعیت قابلیت‌ها) را با **AES-256-GCM** رمز می‌کند و `snapshot.enc` را اینجا پوش می‌کند.
- کلید فقط در URL پنل ادمین می‌آید (بعد از `#` — هرگز به سرور Pages ارسال نمی‌شود) و داخل Secrets بات هم هست.
- بدون کلید، داده‌ها قابل خواندن نیستند.

## باز کردن پنل
لینک کامل (با کلید) را از پنل پیامی ادمین در بات بگیرید: دکمه «🌐 مینی‌اپ پنل ادمین».
